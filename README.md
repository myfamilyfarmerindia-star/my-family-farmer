# My Family Farmer — Crops & Desi Kitchen OS

> **Tagline:** *Your Family. Your Farmer.*
> **Model:** Chemical-free, contract-grown major crops & urban pantry staples (zero perishable vegetables), stored in hermetic grain banks and stone-milled / wood-pressed within 48 hours of delivery.

## What's Included in This Repo
- `index.html` — Interactive 3-in-1 Prototype (**Family App**, **Farmer App (EN/हिन्दी)**, and **Admin Control Tower + Live Unit Economics Simulator**)
- `BUSINESS_PLAN.md` — Upgraded Crops-Only Business Model, 5-Season Crop Calendar, Anti-Fraud Architecture, and 90-Day Lean Pilot Roadmap

## Quick Run Locally
Open `index.html` in any modern browser (zero external dependencies, 100% offline-ready), or serve statically:
```bash
npx serve .
```
